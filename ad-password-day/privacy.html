AD Password Day 개인정보 처리방침

문서 기준일: 2026년 11월 17일

AD Password Day는 Mac에서 사용자가 지정한 회사 Active Directory에 연결해 비밀번호 만료일을 조회하고 비밀번호를 변경합니다. 이 문서는 AD Password Day 앱, s10cho.github.io/passwordbar/ 경로의 안내 페이지와 지원 문의에서 정보를 처리하는 방식을 설명합니다.

Mac에 저장하는 정보

앱은 계정 이름, AD 서버, Kerberos realm, 포트, LDAP 검색 기준, 표시·조회 설정을 이 Mac의 앱 설정에 저장합니다. 마지막 조회 결과, 만료일, 마지막 변경일과 자동 조회 상태도 로컬에 저장합니다. 수동 추정을 사용하면 직접 입력한 변경일과 주기를 저장합니다. 이 정보는 화면 표시, 다음 조회, 만료일 계산에 사용합니다.

비밀번호는 기본 설정에서 저장하지 않습니다. 사용자가 ‘키체인 저장 · 자동 조회’를 켜고 인증에 성공한 경우에만 해당 계정과 연결 설정에 한정해 macOS Data Protection 키체인에 저장합니다. 이 항목은 기기가 잠금 해제된 상태에서 접근하도록 설정하며, 다른 기기로 이전하거나 iCloud로 동기화하지 않는 속성을 사용합니다. 비밀번호 변경이 확인되면 저장을 선택한 경우 새 비밀번호로 교체합니다.

회사 AD와 통신하는 정보

실제 조회·변경 시 계정과 서버 정보, Kerberos 인증 자료를 사용합니다. 비밀번호 변경은 macOS의 Kerberos 기능으로 처리합니다. 만료일은 GSSAPI로 인증하고 암호화한 LDAP 연결로 조회하며, 앱은 협상된 AES 128 또는 AES 256 보호를 확인합니다. 조회하는 정보는 계정의 비밀번호 만료일, 마지막 변경일과 관련 계정 상태입니다.

연결 대상은 사용자가 지정한 회사 서버입니다. AD Password Day는 비밀번호나 AD 조회 결과를 개발자 서버로 보내지 않습니다. 회사 서버는 회사 정책에 따라 인증·접속 기록을 남길 수 있으므로 해당 기록의 처리와 삭제는 회사 IT 담당자에게 문의해 주세요.

인증 작업 중에는 앱 전용 임시 디렉터리에 Kerberos 설정과 티켓 캐시 파일을 만들고, 작업 종료 시 정리합니다. 앱은 사용자의 기본 Kerberos 티켓이나 시스템 Kerberos 설정을 변경하지 않습니다.

저장 중지와 삭제

‘설정…’의 ‘추가 설정’에서 ‘키체인 저장 · 자동 조회’를 끄고 저장하면 자동 인증을 중단하고, 해당 계정·서버 범위의 저장된 비밀번호를 삭제합니다. 계정이나 연결 설정을 바꿀 때도 이전 범위의 비밀번호를 삭제합니다. 키체인이 잠겼거나 접근할 수 없으면 비밀번호를 포함하지 않는 삭제 대기 정보를 로컬에 남겨 이후 삭제를 다시 시도합니다.

앱을 지우기만 해서는 키체인 비밀번호가 삭제된다고 보장할 수 없습니다. 앱을 제거하기 전에 저장을 끄고, Mac의 잠금을 해제한 상태에서 앱을 실행해 삭제가 완료되도록 해 주세요. 삭제가 진행되지 않으면 지원 주소로 문의하세요. 비밀번호를 메일로 보내지 마세요.

설정과 조회 캐시는 이후 실행을 위해 로컬에 유지하며, 같은 항목의 저장·조회 결과로 갱신합니다. 키체인 저장을 끄는 동작은 모든 로컬 설정을 지우는 동작과 다릅니다. 남은 앱 데이터의 제거가 필요하면 지원 주소로 문의할 수 있습니다. 회사 AD 계정과 회사 서버 기록은 AD Password Day가 삭제하지 않습니다.

체험 모드

체험 모드는 합성 계정과 조회 결과를 사용합니다. 체험에서 입력한 값, 설정과 저장된 비밀번호는 체험용 메모리 안에서만 처리합니다. 실제 AD, 시스템 키체인, 일반 사용 모드의 설정·조회 기록과 분리됩니다. 체험 초기화 또는 앱 종료로 체험 데이터를 지울 수 있습니다. 체험에서도 실제 비밀번호를 입력하지 마세요.

분석·광고와 안내 웹사이트

AD Password Day 앱에는 개발자에게 이용 기록을 보내는 분석 기능이나 광고 SDK가 없습니다. s10cho.github.io/passwordbar/와 그 하위 안내 페이지에는 분석·광고 스크립트, 추적 쿠키, 외부 글꼴을 추가하지 않았습니다.

s10cho.github.io/passwordbar/ 안내 페이지는 GitHub Pages에서 제공합니다. 페이지에 접속하면 호스팅 제공자가 IP 주소 등 일반적인 웹 접속 정보를 처리할 수 있습니다. 이는 앱의 회사 AD 통신과 별개입니다. 호스팅 제공자의 처리 방식은 GitHub 개인정보처리방침을 확인해 주세요.

지원 문의

지원 메일을 직접 보내면 발신 이메일 주소와 문의 본문·첨부 파일을 받습니다. 이 정보는 문의 확인과 답변에 사용하고, 문의 처리에 필요한 기간 동안 보관합니다. 삭제를 원하면 같은 주소로 요청해 주세요. 지원 메일 전송은 앱이 자동으로 수행하지 않습니다.

문의에는 앱 버전, macOS 버전, 오류 코드와 재현 순서만 우선 포함해 주세요. 비밀번호, 일회용 인증 코드, Kerberos 티켓이나 회사의 민감한 내부 정보를 보내지 마세요. 화면을 첨부할 때는 계정과 서버 주소 등 필요한 정보 외의 내용을 가려 주세요.

AD Password Day Privacy Policy

Document date: November 17, 2026

AD Password Day connects from your Mac to the company Active Directory server you configure to check password expiry and change a password. This policy describes information processing in the AD Password Day app, the information pages under s10cho.github.io/passwordbar/, and support inquiries.

Information stored on your Mac

The app stores your account name, AD server, Kerberos realm, ports, LDAP search base, and display and refresh settings in its local app preferences. It also stores the latest query result, expiry date, last password-change date, and automatic-refresh state locally. If you use manual estimation, the app stores the change date and period you enter. These values support the display, subsequent queries and expiry calculations.

Passwords are not stored by default. Only when you enable “키체인 저장 · 자동 조회” (Keychain storage and automatic checks) and authenticate successfully does the app store the password in the macOS Data Protection Keychain, scoped to that account and connection configuration. The item is configured for access while the device is unlocked, with attributes that prevent migration to another device and iCloud synchronization. After a confirmed password change, the app replaces the stored password with the new one if you have chosen to store it.

Information used with company AD

Real queries and password changes use account and server information and Kerberos authentication material. Password changes use macOS Kerberos functionality. Expiry queries use a GSSAPI-authenticated and encrypted LDAP connection, and the app checks that AES 128 or AES 256 protection was negotiated. It queries password expiry, the last password-change date and related account status.

The destination is the company server you specify. AD Password Day does not send passwords or AD query results to a developer server. Your company server may retain authentication and access logs under its own policies. Contact your IT team about how those records are handled and deleted.

During authentication, the app creates Kerberos configuration and ticket-cache files in a private temporary directory and cleans them up when the operation ends. It does not change your default Kerberos tickets or system Kerberos configuration.

Turning storage off and deleting data

In “설정…” (Settings), open “추가 설정” (Additional settings), turn off “키체인 저장 · 자동 조회” and save. This stops automatic authentication and deletes the saved password for that account/server scope. Changing the account or connection settings also deletes the password for the old scope. If Keychain is locked or unavailable, the app stores a local pending-deletion record that contains no password and retries deletion later.

Removing the app alone does not guarantee that the Keychain password is deleted. Before removing the app, turn storage off and run the app while your Mac is unlocked so deletion can complete. If deletion does not proceed, contact support. Do not email your password.

Settings and query caches remain locally for later use and are updated when the same settings or query results are saved again. Turning off Keychain storage does not erase all local settings. You can contact support for help removing remaining app data. AD Password Day does not delete your company AD account or your company's server records.

Demo mode

The demo uses synthetic accounts and query results. Values entered in the demo, its settings and saved passwords are processed only in separate demo memory. They are isolated from real AD, system Keychain, and normal-mode settings and query records. Resetting the demo or quitting the app clears demo data. Do not enter a real password in the demo.

Analytics, advertising and information pages

The AD Password Day app has no analytics feature that sends usage records to the developer and no advertising SDK. No analytics or advertising scripts, tracking cookies, or external fonts were added to s10cho.github.io/passwordbar/ or its information subpages.

The s10cho.github.io/passwordbar/ information pages are hosted on GitHub Pages. When you visit a page, the hosting provider may process ordinary web-access information such as your IP address. This is separate from the app's company AD traffic. See the GitHub General Privacy Statement for the hosting provider's practices.

Support inquiries

If you choose to email support, we receive your sender email address, message and attachments. This information is used to understand and answer the inquiry and is retained for the period needed to handle it. To request deletion, contact the same address. The app does not send support email automatically.

Please initially include only the app version, macOS version, error code and steps to reproduce the problem. Do not send passwords, one-time authentication codes, Kerberos tickets or sensitive company information. If you attach a screenshot, redact information that is not needed, including account and server details.
