개인정보처리방침

TokenBar · 시행일 2026년 9월 30일

TokenBar는 사용자가 선택한 이 Mac의 Codex·Claude Code 기록을 기기 안에서 읽습니다. 운영자에게 기록이나 사용량을 전송하지 않습니다.

  • 로컬 처리
  • 외부 전송 없음
  • 광고 없음
  • 추적 없음
  • 로그인 없음

1읽는 데이터

사용자가 허용한 .codex 또는 .claude 폴더 안의 로컬 세션 기록에서 토큰 수와 제공자가 기록한 한도 사용률·초기화 시각을 읽습니다. 세션 기록에는 대화 내용이 함께 들어 있을 수 있지만, 앱은 사용량 계산에 필요한 필드만 해석하고 대화 내용을 화면에 표시하거나 별도로 저장하지 않습니다. Claude 한도 값은 해당 폴더에 이미 존재하는 TokenBar 한도 파일이 있을 때만 읽습니다.

2저장

표시 방식, 갱신 간격, 제공자 순서와 사용자가 선택한 폴더의 읽기 전용 접근 권한을 이 Mac의 앱 저장 공간에 보관합니다. 세션 기록은 복사하거나 서버에 업로드하지 않습니다. 폴더 원본은 해당 CLI 앱이 관리하며 TokenBar가 삭제하지 않습니다.

3네트워크·제3자

현재 macOS 앱에는 계정, 분석 도구, 광고 SDK, 추적기 또는 자체 서버 통신이 없습니다. TokenBar는 사용량, 세션 기록, 설정을 운영자나 제3자에게 전송하지 않습니다.

4권한과 선택

앱은 macOS 파일 선택창에서 사용자가 직접 고른 폴더에 대해 읽기 전용 접근을 요청합니다. 폴더를 선택하지 않으면 해당 제공자의 기록을 읽지 않습니다. macOS 설정에서 접근을 취소하거나 앱을 삭제할 수 있습니다.

5변경과 문의

데이터 처리 방식이 달라지면 배포 전에 이 페이지를 갱신합니다. 문의는 GitHub 이슈에서 받을 수 있습니다. 이슈는 공개될 수 있으므로 세션 기록이나 계정 정보를 올리지 마세요.

Privacy Policy

TokenBar · Effective September 30, 2026

TokenBar reads the Codex and Claude Code folders you select on this Mac. It does not send logs or usage data to the developer.

Data read

The app reads token counts and provider-reported quota percentages and reset times from local session records in the selected .codex and .claude folders. Session files can contain conversation content; TokenBar parses only fields needed for usage totals and does not display or separately store conversation content. Claude quota data appears only when an existing local TokenBar quota file is available.

Storage

Display preferences, refresh interval, provider order, and read-only folder bookmarks are stored in the app's local container. TokenBar does not copy session files or upload them. It does not delete source files.

Network and third parties

The current macOS app has no accounts, analytics, advertising SDKs, trackers, or app server requests. It does not transmit logs, usage totals, or settings to us or to third parties.

Permission and choice

The app asks for read-only access to folders you select in the macOS file picker. It does not read a provider's records until you select that folder. You can revoke access in macOS or remove the app.

Changes and contact

We will update this page before changing how data is handled. For questions, open a GitHub issue. Issues may be public; do not post session logs or account details.
