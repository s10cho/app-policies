개인정보처리방침

TokenBar · 시행일 2026년 11월 19일

TokenBar는 사용자가 이 Mac에서 직접 선택해 연결한 Codex·Claude Code 등의 로컬 기록을 읽기 전용으로 읽습니다. 운영자에게 기록, 사용량 또는 설정을 전송하지 않습니다.

  • 로컬 처리
  • 외부 전송 없음
  • 광고 없음
  • 추적 없음
  • 로그인 없음

1읽는 데이터

사용자가 설정에서 연결한 제공자 폴더의 로컬 세션 기록에서 토큰 수와 제공자가 기록한 한도 사용률·초기화 시각을 읽습니다. 세션 기록에는 대화 내용이 함께 들어 있을 수 있지만, 앱은 사용량 계산에 필요한 필드만 해석하고 대화 내용을 화면에 표시하거나 별도로 저장하지 않습니다. Claude 한도 값은 해당 폴더에 이미 존재하는 TokenBar 한도 파일이 있을 때만 읽습니다.

2저장

표시 방식, 갱신 간격, 제공자 순서, Task Budget의 입력값과 사용자가 선택한 폴더의 읽기 전용 security-scoped bookmark를 이 Mac의 앱 저장 공간에 보관합니다. 재실행 후에도 연결과 입력값이 유지됩니다. 세션 기록은 복사하거나 서버에 업로드하지 않으며, 폴더 원본은 해당 CLI 앱이 관리하고 TokenBar가 삭제하지 않습니다.

3네트워크·제3자

현재 macOS 앱에는 계정, 분석 도구, 광고 SDK, 추적기 또는 자체 서버 통신이 없습니다. TokenBar는 사용량, 세션 기록, Task Budget 입력값 또는 설정을 운영자나 제3자에게 전송하지 않습니다.

4권한과 선택

처음 실행할 때 TokenBar는 폴더 접근을 요청하지 않습니다. 사용자가 제공자별 macOS 파일 선택창에서 ~/.codex, ~/.claude 등 원하는 폴더를 직접 선택한 경우에만 그 폴더를 읽기 전용으로 연결합니다. 설정에서 각 제공자 연결을 해제할 수 있습니다. 앱은 선택한 폴더에 쓰거나 Claude Code 설정을 바꾸지 않습니다. Claude 한도 연동은 선택 사항이며, 앱이 복사해 주는 안내문을 사용자가 Claude Code에 직접 붙여 넣어 구성합니다. 연동을 구성하면 Claude Code가 한도 사용률과 초기화 시각만 ~/.claude/token-bar-rate-limits.json에 저장합니다.

5Task Budget

Task Budget은 계정이나 폴더 연결 없이도 사용할 수 있는 기기 내 작업예산 플래너입니다. 총 예산, 사용량, 작업 수를 바탕으로 남은 예산과 작업당 예산을 로컬에서 계산하며, 연결한 제공자의 오늘 측정 토큰 사용량을 계획에 가져올 수 있습니다. 이는 사용자가 세우는 작업예산으로, 제공자 또는 구독 한도와는 별개입니다.

Privacy Policy

TokenBar · Effective November 19, 2026

TokenBar reads local Codex, Claude Code, and other provider records only from folders that you choose and connect on this Mac, read-only. It does not send logs, usage, or settings to the developer.

Data read

The app reads token counts and provider-reported quota percentages and reset times from local session records in provider folders you connect in Settings. Session files can contain conversation content; TokenBar parses only fields needed for usage totals and does not display or separately store conversation content. Claude quota data appears only when an existing local TokenBar quota file is available.

Storage

Display preferences, refresh interval, provider order, Task Budget inputs, and read-only security-scoped bookmarks for folders you select are stored in the app's local container. Connections and inputs remain after relaunch. TokenBar does not copy session files, upload them, or delete source files.

Network and third parties

The current macOS app has no accounts, analytics, advertising SDKs, trackers, or app server requests. It does not transmit logs, usage totals, Task Budget inputs, or settings to us or to third parties.

Permission and choice

On first launch, TokenBar does not request folder access. It connects a folder such as ~/.codex or ~/.claude read-only only after you choose it in the provider-specific macOS file picker. You can disconnect each provider in Settings. The app does not write to selected folders or change Claude Code settings. The Claude quota bridge is optional: you configure it by pasting a prompt the app copies into Claude Code, and Claude Code then stores only quota percentages and reset times in ~/.claude/token-bar-rate-limits.json.

Task Budget

Task Budget is an on-device work-budget planner that can be used without an account or folder connection. It calculates remaining and per-task budgets locally from the total budget, amount spent, and task count. When you connect a provider, you can import that provider's measured token usage for today into a plan. A Task Budget is your own planning budget, separate from a provider or subscription limit.
